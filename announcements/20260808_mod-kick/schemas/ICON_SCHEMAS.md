# Nano-banana icon schemas — `/mod-kick` announcement

Style lock for all icons (feed these schemas to image gen / nano-banana):

## Global style

- Surf-culture editorial illustration, not corporate SaaS
- Palette: deep ocean ink `#1a2f3d`, foam `#f4f0e6`, copper `#bd6d36`, olive
  wash `#8f9171`, dusk blue `#304f78` (match wavves site tokens)
- Flat / limited-detail poster shapes; soft grain; no purple neon; no 3D gloss
- Typography in-image: optional single word in IBM Plex Mono–like sans, small
- Aspect: square 1:1 for icons; one wide 16:9 hero optional
- Metaphor: **kick out** = yield the wave mid-ride so another rider takes the
  face; software packing is the *mechanism*, surfer speech is the *vibe*

## Icon 01 — KICK OUT (hero metaphor)

**Filename:** `icon_01_kick_out.png`  
**Schema:**
- Left: surfer on a steep face, mid-carve, body leaning back off the lip
  (kick-out posture), board tipping away from the pocket
- Right / behind: second surfer paddling into the open face you just yielded
- Small foam trail connecting them like a handoff line
- Tiny floating label (optional): `KICK OUT`
- Mood: generous yield, not wipeout; clean evening light

## Icon 02 — PUBLISH THE SET (git packing)

**Filename:** `icon_02_publish_set.png`  
**Schema:**
- Beach wax-box / daybag on sand morphing into a sealed “set pack”: stacked
  flat cards labeled as files (findings, receipt, paste) tied with a copper
  leash cord
- Behind: a distant git-like lighthouse beacon (simple tower + beam) = remote
- Motto space: `pack the set → send it out`
- Emphasize allowlist thinness: only a few cards, not a whole quiver spilled

## Icon 03 — LEASH (thin copy-in)

**Filename:** `icon_03_leash.png`  
**Schema:**
- Two boards on different breaks (two small shorelines) connected by a thin
  coiled **leash** cord carrying 2–3 tiny sealed vials/scrolls (the deps)
- Cord is delicate; broken/overstuffed leash shown as a faded ghost (don’t)
- Label: `LEASH` — not “vendor”
- Mood: tether, not tow-truck

## Icon 04 — OTHER BREAK (cross-environment)

**Filename:** `icon_04_other_break.png`  
**Schema:**
- Split panel: left beach phone/laptop with a one-line paste chalked on a
  wax comb; right: different coastline/sunrise, same board silhouette arriving
- Arrow of foam from left to right labeled `pull @ hash`
- No Desktop-folder fetish; the ocean between = the remote

## Icon 05 — NOT ROTATE (contrast)

**Filename:** `icon_05_not_rotate.png`  
**Schema:**
- Two panels. Top: same lineup, same break, fresh jersey number `O0.R(N+1)` =
  rotate / stay in the family
- Bottom: kick out across a channel to a new break = different environment
- Clear X or “≠” between panels
- Label top `ROTATE` bottom `KICK`

## Negative space (never draw)

- Shopping “vendor” carts, npm logos, purple AI glow, wipeout comedy, or
  weather-app heat maps
