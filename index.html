wavves kits help you trust what a Cursor agent says it did. gate-and-proof checks a claim of done against a test you can run. handoff-check checks a handoff before a new thread starts work. A bundle adds rotation-audit for work that runs across many threads. All kits come from research on how agents learn to use skills. Every kit is for sale on the Agensi marketplace.

Kit

/gate-and-proof

Asks for proof before a task counts as done. Each claim becomes a gate with a check you can run. The result is saved as a JSON file. Someone other than the author grades it.

Kit

/handoff-check

Checks a handoff when a new agent thread takes over. Commits and file paths in the handoff are compared against git and the disk. A JSON task list is checked for duplicate ids and bad statuses. The same check also catches loops in the task list.

Demos

Each kit video shows a real run of the kit on a throwaway repo. A script wrote every file in the sample run videos with no live agent at the keyboard. Every sample project is invented for the demo.

Folder layout for an audited repo

A sample project keeps its handoff history as plain files on disk. The video opens the registry file first. Next come the task folders and then the folder of rotation files. A rotation-audit run reads files laid out the same way. No kit builds the layout for you, so the video serves as a model for your own repo.

Sample run 1 with both checking kits

A script replays a sample project one commit at a time. After each step the run checks the proof file with gate-and-proof and compares the handoff claims against git and disk with handoff-check.

Sample run 2 with a second project

A second sample project goes through the same replay. Each commit message names the step that made it, so you can match every check to its commit.

Sample run 3 across two rotations

A longer sample run passes work between threads twice. At the end the run calls all three kits, rotation-audit included.
