paid kits for Cursor agents · on Agensi

wavves kits help you trust what a Cursor agent says it did. gate-and-proof checks a claim of done against a test you can run. handoff-check checks a handoff before a new thread starts work. Both kits come from research on how agents learn and use skills, and both are sold on Agensi.

/gate-and-proof

Asks for proof before a task counts as done. Each claim becomes a gate with a check you can run. The result is saved as a JSON file, and someone other than the author grades it.

/handoff-check

Checks a handoff when a new agent thread takes over. Commits and file paths in the handoff are compared against git and the disk. A JSON task list is checked for duplicate ids, bad statuses and loops.
