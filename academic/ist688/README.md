# wavves class reading for IST 688

Draft for review. This folder is a class reading for Building Human-Centered AI Applications. It is not the sold skill package. It does not add features, metrics or taxonomy terms.

The course document is [wavves-for-ist688.pdf](wavves-for-ist688.pdf). It has the charts, the usage examples, the glossary and the concept tables. The markdown files repeat that reading for search.

| File | What it holds |
|:-----|:--------------|
| `wavves-for-ist688.pdf` | Course document. Computer Modern handout with figures and tables. |
| `wavves-for-ist688.tex` | Source for that PDF. Build with `pdflatex`. |
| `usage.md` | Published prompts and the worked session. |
| `glossary.md` | Wavves terms kept as spelled, with the class meaning beside each one. |
| `concept-map.md` | Class ideas mapped to real functions. |
| `sources.md` | What was included and what was left out. |

Nothing in this folder has been shared with the class.
